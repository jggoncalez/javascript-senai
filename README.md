# Exercícios Resolvidos em Aula

Este repositório contém os exercícios e desafios realizados durante as aulas do curso "Técnico em Desenvolvimento de Sistemas" da escola **SENAI Limeira Luiz Varga**. 

Os conteúdos abordam HTML, CSS e JavaScript, com o objetivo de praticar e consolidar os conceitos aprendidos em sala de aula.

## Conteúdo
- **HTML**: Estruturação de páginas, links, imagens, tabelas, formulários, etc.
- **CSS**: Estilização de elementos, layouts, Flexbox, e responsividade.
- **JavaScript**: Manipulação do DOM, funções, eventos, e interação com o usuário.

Esse repositório será atualizado conforme os exercícios e desafios forem sendo realizados nas aulas.
